# Windows laptop setup

1. Open the green `Code` button on this repository and choose `Download ZIP`.
2. Extract it to `C:\YesTrader-Research`.
3. Open that folder in Codex. Codex can read `AGENTS.md`.
4. **Important:** this repository currently contains research instructions, audit notes and manifests; it does NOT yet contain all historical original CSV files or the separately prepared 13-CSV backup ZIP. GitHub Download ZIP does not include those absent files.
5. Put any independently downloaded CSV backups in `02_CSV_원본` without overwriting originals; verify against the manifest.
